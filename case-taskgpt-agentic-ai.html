Agentic AI

Build your own AI agent

Anyone can build an agent: start from a ready-made instance, add tools and connectors, and watch its chain of thought in a live preview.

  • Only designer

TaskGPT is the AI suite I designed at TaskUs for agents on live customer calls, and for the people who set up, measure and improve the AI behind them. I was the only designer, from 2022 to 2025. Agentic AI is one of its 11 products.

See all of TaskGPTRead the full case study

Build AI agents that do work with tools, not only answer questions. I designed it in early 2025, and it went live.

The story

Our SVP proposed a system where anyone can create their own agent. We were among the first to try, and we were all learning. I simplified it by giving people every brick an agent needs to run. They start from ready-made instances built on real use cases, so they can build fast and simply, with no loss of capability. The builder holds every setting an agent needs, step by step, so nobody is overwhelmed.

What I designed

  • A framework first. Six layers: models, tools, knowledge and memory, audio and speech, guardrails, and orchestration. Each layer became a part of the builder.
  • Version 1, inside the chatbot setup. LLMs, tools and environment; add or edit internal and external tools and their parameters; a feedback switch; and how many days to keep logs.
  • The new AgenticAI app. Dashboard, Agents and Connectors, plus functions, web search, file search, computer use, a form builder and email templates.
  • The agent builder. Name; system instructions (role and agent instruction); model (Amazon Bedrock, OpenAI or PaLM 2); tools (file search, code interpretation, functions); connectors (ServiceNow, Zendesk, Power BI, Kustomer, Jira, Workday, Slack); and the response format.
  • A live preview beside the form. It shows the agent's chain of thought: what it searches (knowledge base, TaskGPT database, web) and which tools it reads (for example Power BI, Workday and ServiceNow). Logs are one click away.
  • A flow canvas for guided conversations: a start node, messages with options, branches, and Create Ticket nodes with a tag, a model and a prompt. Save as a draft, then Launch.

Design decisions

  • Start from a ready-made instance, not a blank page.
  • One step at a time. Every setting an agent needs is there, without overwhelming the person.
  • Show the thinking. When an agent acts on business systems, people need to see what it read before they trust what it did.
  • Form and preview side by side, so every change shows its effect at once.
