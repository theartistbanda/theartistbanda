Chatbotify

Build a chatbot without code

A client's chatbot without code: knowledge base, model, masking and small talk. Setup went from about a day in code to minutes.

TaskGPT is the AI suite I designed at TaskUs for agents on live customer calls, and for the people who set up, measure and improve the AI behind them. I was the only designer, from 2022 to 2025. Chatbotify is one of its 11 products.

See all of TaskGPTRead the full case study

Create and manage a chatbot (a Knowledge Assist) for each client, with no code.

Chatbotify was the configuration layer before Agentic AI. Clients used it to manage their chatbots, and admins used it to create chatbots for clients. Agentic AI grew out of it. The first instance was built entirely in code, which took about a day. I designed Chatbotify so that a new client instance took minutes, with room for each client's own customisations.

What I designed

  • A stepped setup: General, Knowledge Base and App Integrations, with Basic and Advanced tabs.
  • Knowledge base setup. Choose a version or add a new one. Single or bulk upload. Create a new repository or update one. Four sources: local files, Google Drive, Glowstick API or an external API. Then the embedding model, the extraction method and the chunk method.
  • "Info about this KB". Upload time, total cost, tokens used, total chunks and the vector index, so the cost of knowledge shows at setup.
  • An upload tracker in five steps: file processing, text extraction, embeddings, vector database and knowledge repository.
  • Structure checks. Each file shows if it has markdown headings. A warning asks for at least 3 headers or 200 lines. A PDF gets a warning to use DOC or TXT, because the system cannot read headings in a PDF. "More info" counts the headings at each level.
  • Advanced settings. The provider and language model (GPT-3.5, GPT-4, PaLM 2, Llama 2, Jurassic-2, Titan and Claude 2) and the embedding model; small talk questions and answers; PII masking rules; playground instructions; welcome message; promote; app integrations.
  • Master configuration for rules that apply to every chatbot: master small talk, master masking, and BCP for AI.

Design decisions

  • Tell people why a file will fail before it fails. Files without headings gave conflicting or missing answers, so the upload checks structure first.
  • Two levels of rules. TaskUs admins create master rules, such as masking and small talk, once. Each client then switches them on or off for its own chatbot.
